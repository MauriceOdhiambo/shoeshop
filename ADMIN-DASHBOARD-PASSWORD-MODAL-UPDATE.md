# Admin workspace refinement

- Removed the duplicate summary KPI cards from the admin landing workspace. Business metrics are presented in the Super Admin-only Business Analysis section.
- Replaced the inline password form with a focused account-security dialog. It includes current password, new password, confirmation, minimum-length guidance, close/cancel actions, and a dark responsive design.
- Renamed the header action to “Account security”.

No spreadsheet setup or administrator migration is required for this UI update. Existing API-based password change flow is retained.
